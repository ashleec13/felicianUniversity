# Felician University Recruitment Site

This single-page recruitment site presents Felician University through its programs, campuses, student life, admissions path, cost information, and final application calls to action.

## Run locally

Open `index.html` in a browser, or serve the folder with any static web server. The page loads Bootstrap 5.3 and the Adobe Typekit fonts from their CDNs, so an internet connection is needed for those external dependencies.

## Site features

- Hero section with Felician branding, recruitment message, and program CTA.
- About content covering the university type, New Jersey locations, NYC access, and close-knit learning experience.
- Four interactive program panels: Nursing, Computer Science, Business, and Psychology.
- Student-life gallery featuring DII sports, clubs, games, residence life, events, and green spaces.
- Location image selector, animated student-to-professor ratio, and campus shuttle switcher.
- Bootstrap admissions tabs covering application expectations, tuition, financial aid, campus visits, and enrollment.
- Responsive navigation that collapses into a mobile menu.
- Final Apply, Visit Campus, and Request Info calls to action.

## Project structure

- `index.html`: semantic page content and Bootstrap component markup.
- `style.css`: custom Felician color palette, typography, layout, responsive rules, and component styling.
- `script.js`: navigation, image selector, counters, custom tabs, and campus interactions.
- `pictures/`: hero, logo, program, campus, news, and student-life images.
